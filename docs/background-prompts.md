# Celebration background generation

These five project assets were generated with the built-in image-generation tool. The original supplied `image.png` was a style reference. Neither logo was passed to generation; both exact original files are composited separately by Konva.

Shared prompt: Square decorative background only for an organization anniversary frame. Decoration stays mostly in the outer 8% perimeter; keep the top 20%, large central photo area, and bottom name area calm. High-end silky textures, metallic gold reflections, detailed studio lighting and rich red/green finishing. No words, numbers, letters, logos, people, faces, crowns, watermarks or inset outlines. One square background, no contact sheet.

| Asset | Specific visual prompt |
| --- | --- |
| `public/templates/silk.webp` | Warm ivory pearl, glossy crimson and emerald silk ribbons, bevelled gold edges, golden bokeh, sweeping corner and lower arcs. |
| `public/templates/emerald.webp` | Deep emerald velvet, tonal brocade, illuminated art-deco double gold lines, crimson folds at opposing corners, gold dust and warm reflections. |
| `public/templates/pearl.webp` | Bright pearl satin, champagne-gold waves, embossed curves, emerald and red perimeter folds, small gold spheres and an ethereal warm glow. |
| `public/templates/ruby.webp` | Deep ruby satin, glowing gold ornamental corners, emerald folds, diagonal gold foil waves, detailed fabric grain and studio lighting. |
| `public/templates/gold.webp` | Ivory silk-paper, symmetrical gold filigree, tapered green/red silk bands, tiny sparkle highlights and a luminous golden outer arc. |

Each finished background is stored locally as an optimized 1080px WebP (approximately 90–130 KB). Official logos remain the unchanged original PNGs. Name, designation, anniversary heading, gold photo borders and clipped member portrait are deterministic canvas elements above the background.
